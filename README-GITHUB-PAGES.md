# Leena Love Website — GitHub Pages Ready

## Upload
Upload the contents of this ZIP to the root of your GitHub repository.

## Publish
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, choose **GitHub Actions**.
4. Push/commit the files to the `main` branch.
5. Open the Actions tab and wait for **Deploy to GitHub Pages** to finish.
6. GitHub will show the Pages URL under Settings → Pages.

The included `.github/workflows/deploy.yml` automatically installs dependencies, builds the Vite project, and publishes `dist`.

Keep the `assets` folder and its media files in the same locations as provided.
